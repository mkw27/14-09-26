# Fonts

Placez ici les fichiers de police Inter au format .woff2 :

- inter-regular.woff2
- inter-medium.woff2
- inter-semibold.woff2

## Où les obtenir

1. Allez sur https://fonts.google.com/specimen/Inter
2. Cliquez sur "Get font" puis "Download all"
3. Décompressez, ouvrez le dossier `static/`
4. Convertissez les fichiers .ttf en .woff2 sur https://cloudconvert.com/ttf-to-woff2
5. Renommez-les exactement comme ci-dessus
6. Placez-les dans ce dossier
